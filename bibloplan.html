BLILOPLAN: YOUR PERSONALIZED INTELLIGENT READING CURATOR

Role: Project Lead | Status: Commin soon ..Jan 2026

OVERVIEW

BiblioPlan is a Full-Stack, Serverless AI Agent designed to eliminate the mental friction of managing reading goals, thereby driving user consistency. The system automates the entire planning-and-reminder loop.

Built on a robust architecture, the agent uses Python/Flask to power a web dashboard for list management and configuration. The application is deployed to Google Cloud Run and triggered daily by Cloud Scheduler. Upon activation, the agent retrieves user progress from Firestore, feeds the context to the Gemini API to generate a personalized, motivational plan, and securely dispatches the final content via transactional email.

This project showcases expertise in serverless infrastructure, full-stack development, and practical LLM integration for proactive, automated user solutions.

MOTIVATION

This project is fundamentally driven by personal struggle against information entropy and the cognitive cost of curation. I was often struggling not just with finding the time to read, but with the mental friction required to curate, track, and prioritize content, often resulting in good academic content being "lost" or professional knowledge becoming outdated. Existing reading trackers and news aggregators are fundamentally passive and reactive, insufficient because they are merely firehoses of information; they do not filter, personalize, or, most critically, synthesize the content relevant to my specific goals.

My work directly addresses the critical gap between raw, overwhelming information and actionable, synthesized knowledge delivered proactively. The agent acts as a personal, intelligent reader that not only curates the reading list based on high-stakes academic and professional objectives but also reduces cognitive load by providing summaries. AI is necessary for this purpose because the problem is not a simple tracking task, but a complex challenge of language and context; only an LLM (Gemini API) can efficiently filter content, reason about a user's progress, and transform dense material into a motivational, digestible, and personalized daily reading plan.
